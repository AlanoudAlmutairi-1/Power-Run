Power Run



Description



Power Run is a small Unity game where the player must collect three energy cells, avoid a security drone, and reach the exit before the countdown timer runs out.



&#x20;Setup Instructions



1\. Open the project in Unity.

2\. Open the `Level1` scene.

3\. Press Play to start the game.



Controls



\- W A S D - Move

\- ESC - Pause



Objective



\- Collect all 3 Energy Cells.

\- Avoid the Security Drone.

\- Manage your health and the countdown timer.

\- Reach the Exit to win.



&#x20;Project Structure



\- `Assets` - Game assets and project files.

\- `Assets/Scripts` - C# game scripts.

\- `Assets/Audio` - Game audio.

\- `Level1` - Main game level.



Gameplay Features



\- Player movement and collision.

\- Security Drone patrol, detection, chase, and attack.

\- Three collectible Energy Cells with sound and visual effects.

\- Player health and damage system.

\- Countdown timer.

\- Locked Exit until all Energy Cells are collected.

\- Win and Loss states.

\- Pause and Restart functionality.

\- HUD showing health, collected cells, and remaining time.
